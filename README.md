# UGC Unscripted — Creator Tracker

A lightweight CRM to track UGC creators: contact info, social handles, pipeline status, and notes.

## Features

- **Dashboard stats** — total creators, contacted, booked, conversion rate
- **Pipeline bar** — visual breakdown of your creator pipeline
- **Status dropdown** — New → Contacted → Negotiating → Booked → Completed / Declined
- **Search & filter** — find creators by name, handle, niche
- **Sortable columns** — sort by name, niche, status
- **Export CSV** — download your creator list
- **Local storage** — data persists in your browser

## Tech Stack

- React 18 + Vite
- Tailwind CSS
- Lucide icons
- localStorage for persistence

## Getting Started

```bash
npm install
npm run dev
```

## Deploy

Connect this repo to [Vercel](https://vercel.com) — it auto-detects Vite and deploys.
